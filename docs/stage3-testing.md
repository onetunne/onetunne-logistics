# Етап 3: покрокове тестування через Render і Shopify (тестовий магазин)

Що НЕ робимо під час тестування:
- не створюємо реальних накладних (змінну `NOVA_POST_SHIPMENTS_ENABLED` **не додаємо**);
- не підключаємо основний магазин onetunne.com;
- не змінюємо й не вимикаємо наявний застосунок розрахунку доставки (CCS) у Shopify;
- **не натискаємо** «Підключити до Checkout» — розрахунок у Checkout поки лишається вимкненим.

Тривалість: ~30–40 хв. Після кожного кроку — короткий результат («OK» або знімок екрана помилки).

---

## Крок 1. Render: гілка й змінні
1. Render → сервіс `onetunne-logistics-shopify-test` → **Settings → Build & Deploy → Branch** = `claude/stage-3-nova-global` → Save.
2. **Environment**:
   | Ключ | Значення |
   |---|---|
   | `SCOPES` | `write_orders,read_products,read_inventory,write_merchant_managed_fulfillment_orders,write_shipping` |
   | `NOVA_POSHTA_API_KEY` | уже внесено (не змінювати) |
   | `NOVA_POST_SHIPMENTS_ENABLED` | **не додавати** |
3. **Save** → **Manual Deploy → Deploy latest commit**. Дочекайтеся «Live».
4. **Logs** → у пошуку введіть `carriers.registered`. Має бути `default: nova_post` і `novaPostShipmentCreation: disabled`.
   Також знайдіть `NOVA-CHECK` — рядки 1–3 мають бути «OK».

## Крок 2. Shopify Dev Dashboard: нові дозволи
1. dev.shopify.com → Apps → ONE TUNNE Logistics → **Versions → Create version**.
2. Scopes — той самий рядок, що в `SCOPES` (крок 1) → **Release**.
3. Відкрийте застосунок у тестовому магазині → підтвердьте нові дозволи.
4. Застосунок → **Налаштування → Синхронізація Shopify** → блок «Дозволи етапу 3»: обидва дозволи — «надано».

## Крок 3. Налаштування (Налаштування → розділи нижче)
1. **Відправник**: назва компанії, контакт, телефон, email, країна UA, місто, індекс, адреса; **ЄДРПОУ/ІПН**;
   EORI та IOSS — якщо є; «Відділення/пункт прийому перевізника» — номер відділення Нової пошти (напр. `32521/1`). Зберегти.
2. **Nova Post**: хто платить; номер договору; **тариф — оберіть один** (напр. «Стандарт»); валюта тарифів `UAH`. Зберегти.
   Статус «Створення реальних накладних: вимкнено» — так і має бути.
3. **Митні документи**: умови поставки (DAP/DDP), мета експорту, тип інвойсу. Адреса реєстрації одержувача —
   поки **«Не передавати»** (див. крок 8). Зберегти.
4. **Відстеження та Shopify**: «Повідомляти клієнта» — **вимкнено**. Зберегти.

## Крок 4. Перевірка підключення Nova Post (без накладних)
1. Налаштування → **Перевірка підключення Nova Post** → «Перевірити підключення».
2. Очікується: «Вхід за ключем: OK», дві таблиці розрахунку (без договору і з договором), «Відправлення кабінету: валюта договору: …».
3. Перевірте:
   - **валюта**: «валюта договору» (з ваших відправлень) — UAH? (у відповіді розрахунку Nova Post валюта не вказується);
   - **договірні тарифи**: сума «До сплати» у таблиці «з вашим договором» для 0,5 кг Київ → Берлін збігається з вашим
     тарифом (бізнес-кабінет або договір)? Знижка відображається, якщо договір її передбачає?
4. Лише якщо все збігається — «Підтвердити валюту й тарифи». Якщо ні — **не підтверджуйте**, надішліть мені знімок таблиць.

## Крок 5. Товари: митні дані, вага, габарити
1. Розділ **Товари** → фільтр «Без митних даних».
2. Для 1–2 товарів заповніть: HS-код **8–10 цифр** (УКТ ЗЕД; 6-значні Nova Post не приймає), країну походження,
   опис англійською й українською, матеріал, вагу, габарити → Зберегти. Біля полів — позначка «змінено в застосунку».
3. Налаштування → Синхронізація Shopify → «Синхронізувати всі товари». Після завершення відкрийте ті самі товари:
   ваші значення **збереглися** (синхронізація їх не перезаписує).

## Крок 6. Тестове замовлення: перевірка, інвойс, захист від реальних накладних
1. Створіть тестове оплачене замовлення до Німеччини (адреса виду «Hauptstraße 12», індекс, телефон, email).
2. Застосунок → Замовлення → це замовлення → «Перевірити дані». Виправте проблеми (якщо є).
3. «Створити накладну» → очікується повідомлення, що створення реальних накладних Nova Post **вимкнено**
   (накладна не створюється, у Nova Post нічого не надсилається).
4. «Комерційний інвойс для друку» → перевірте реквізити, HS-коди, вагу, суми → «Друкувати» (можна в PDF).

## Крок 7. Тестовий розрахунок вартості (Checkout не вмикаємо)
1. Налаштування → Розрахунок доставки в Checkout → курси валют (напр. EUR — скільки гривень за 1 EUR), націнка → Зберегти.
2. «Тестовий розрахунок»: DE, Berlin, 10178, 500 г, вартість 50 EUR → видно один тариф (обраний у кроці 3) з цінами.
3. Прапорець «Увімкнено» і кнопку «Підключити до Checkout» **не чіпаємо**.

## Крок 8. Адреса реєстрації одержувача (DE, SK, HU, FR) — рішення
Nova Post вимагає адресу реєстрації одержувача для цих країн. Дозволяйте «Передавати адресу доставки» **лише** після
підтвердження в Nova Post (менеджер/договір), що адреса доставки допустима як адреса реєстрації; тоді позначте
підтвердження в розділі «Митні документи». Без підтвердження накладні до цих країн не створюються.

## Крок 9 (необов'язково). Відстеження й трек-номер у Shopify без створення накладної
Лише якщо маєте номер **уже наявної** накладної Nova Post (створеної раніше в кабінеті):
1. Тестове замовлення → «Прив'язати номер накладної» → номер → «Оновити статус» — статус підтягується з Nova Post (лише читання).
2. Якщо посилку вже прийнято перевізником, замовлення отримує «Передано перевізнику», а в тестовому магазині з'являється
   виконання з трек-номером (лист клієнту не надсилається).

## Що надіслати мені
- Крок 1: рядок `carriers.registered` і рядки `NOVA-CHECK`.
- Крок 4: знімок результатів перевірки підключення (обидві таблиці) і чи збігаються суми з договором.
- Крок 5–7: «OK» або знімок помилки.
