# ONE TUNNE Logistics

Приватна ERP-система для міжнародної логістики магазину onetunne.com (Embedded Shopify App).
Поточний стан — етап 1 (основа й демо) прийнято; етап 2 (Shopify) і етап 3 (міжнародні відправлення Nova Post)
реалізовано й очікують перевірки власником (див. `ROADMAP.md`).

- `REQUIREMENTS.md` — повна кінцева концепція (усі етапи).
- `ROADMAP.md` — етапи, прогрес, обмеження, наступні кроки.
- `CLAUDE.md` — технічні рішення та правила розробки.

## Демо: що це
Автономна версія без Shopify, без ключів і без платних сервісів. Усі замовлення вигадані,
накладні створює **тестовий перевізник**, у Shopify і перевізникам нічого не надсилається.
Дані зберігаються у вбудованій базі (PGlite) у папці `.data/demo-db`.

## Запуск на ПК (Windows / macOS / Linux)
1. Встановіть Node.js 22 LTS: https://nodejs.org (кнопка «LTS»).
2. Завантажте код: на GitHub → кнопка **Code → Download ZIP** (гілка `claude/one-tunne-logistics-stage-1-x4yjmz`) і розпакуйте.
3. Відкрийте **Командний рядок** у папці проєкту:
   - Windows: відкрийте папку в Провіднику, клацніть в адресному рядку, введіть `cmd` і натисніть Enter.
     (PowerShell може блокувати npm — використовуйте саме `cmd`.)
   - macOS: Термінал → `cd ` і перетягніть папку у вікно.
4. Виконайте по черзі:
   ```
   npm ci
   npm run demo
   ```
5. Відкрийте в браузері: http://localhost:3000/demo

Зупинити: `Ctrl + C` у терміналі. Скинути демо-дані: «Налаштування → Скинути демо-дані» або видаліть папку `.data`.

### Відкрити з iPhone у тій самій Wi-Fi мережі
1. Запустіть демо на ПК (кроки вище).
2. Дізнайтеся IP-адресу ПК: Windows — `ipconfig` (рядок IPv4, напр. `192.168.1.25`); macOS — Системні налаштування → Wi-Fi → Деталі.
3. На iPhone у Safari відкрийте `http://192.168.1.25:3000/demo` (ваша адреса). Якщо не відкривається — дозвольте Node.js у брандмауері.

## Розміщення демо в інтернеті (безкоштовно, Render)
1. Зареєструйтеся на https://render.com (можна через GitHub).
2. **New → Blueprint** → оберіть репозиторій `onetunne-logistics`. У полі **Branch** оберіть
   `claude/one-tunne-logistics-stage-1-x4yjmz` (у `main` поки лише початковий порожній коміт) → Render знайде `render.yaml`.
3. Введіть `DEMO_PASSWORD` (пароль для доступу до демо) → **Apply**.
4. Після збірки (5–10 хв) відкрийте адресу виду `https://onetunne-logistics-demo.onrender.com/demo` на iPhone або ПК.

Обмеження безкоштовного плану: сервіс «засинає» після простою (перше відкриття ~1 хв), демо-дані скидаються при перезапуску.
Пам'ять: демо-сервер використовує ~400 МБ (виміряно локально; ліміт Free — 512 МБ). Розгортання на Render ще не перевірялося —
якщо Render повідомить про нестачу пам'яті, потрібен платний план Starter (лише з вашого дозволу).
Необов'язкові налаштування (пароль демо тощо) можна також записати у файл `.env` (див. `.env.example`).
Демо не використовує ключі Shopify — не додавайте їх у цей сервіс.

## Команди розробника
| Команда | Що робить |
|---|---|
| `npm run dev` | режим розробки (для демо створіть `.env` з `DEMO_MODE=true`, див. `.env.example`) |
| `npm run demo` | збірка й запуск демо |
| `npm run check` | перевірка типів + тести + збірка |
| `npm test` | автоматичні тести |
| `npm run test:e2e` | перевірка інтерфейсу в браузері (потрібен Playwright і запущене демо) |
| `npm run db:generate` | нова міграція після зміни схеми БД |

## Робоча версія (етап 2+)
Потребує PostgreSQL (`DATABASE_URL`), застосунку в Shopify Dev Dashboard (Custom Distribution) і ключів у змінних середовища
(`.env.example`). Маршрути `/app/*` завжди проходять автентифікацію Shopify. На етапі 1 робочу версію не підключено.
