# Графічний дизайн

## Як працювати без «малювання очима»
1. Макет як код: SVG або HTML/CSS (точні розміри, кирилиця, бренд-кольори) → рендер у PNG:
   `playwright-cli` (скріншот сторінки) або Chrome headless. Варіанти (ціни/тексти) — з даних, одним скриптом.
2. Перевір результат одним зображенням (зменшена копія), а не серією скріншотів.
3. Пакетна обробка готових зображень: ImageMagick (якщо встановлено) — `magick in.jpg -resize 2048x2048 -quality 85 out.jpg`;
   без нього — FFmpeg: `ffmpeg -i in.png -vf scale=1080:-1 out.jpg`.
4. Складна ручна робота (ретуш, ілюстрації) — Affinity by Canva (безкоштовний) через конектор у Claude Desktop, якщо підключено.

## Розміри
| Призначення | Розмір |
|---|---|
| Instagram пост | 1080×1350 (4:5) або 1080×1080 |
| Сторіс / Reels обкладинка | 1080×1920 (у сітці профілю видно 3:4 центр) |
| YouTube мініатюра | 1280×720 |
| Facebook/OG-зображення сайту | 1200×630 |
| Товар Shopify | 2048×2048 (квадрат, однаковий фон для всіх товарів) |
| Email-банер | 600–1200 px завширшки |

## Правила якості
- Ієрархія: 1 головний меседж, ≤ 7 слів на банері; CTA контрастною кнопкою.
- Контраст тексту до фону ≥ 4.5:1; текст ≥ 4% висоти кадру для мобільних.
- Не більше 2 шрифтів; кирилиця обов'язкова; шрифти лише вільні (OFL) або встановлені.
- Узгодженість бренду: кольори/шрифти з brand-файла власника (спитай, якщо немає; збережи в проєкті).
- Експорт: PNG для графіки з текстом, JPG 80–85% для фото, WebP для сайту.

## Генерація зображень
Claude не генерує фото напряму. Варіанти: стоки з ліцензією, фото власника, або локальна генерація (ComfyUI — лише
з потужною відеокартою і після згоди власника; перевіряй ліцензію моделі на комерційне використання).
