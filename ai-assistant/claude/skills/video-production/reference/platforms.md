# Формати платформ (станом на 2026-11; ліміти часто змінюються — перевіряй у довідці платформи перед публікацією)

| Платформа | Кадр | Пресет mtk | Примітки |
|---|---|---|---|
| TikTok | 9:16, 1080×1920 | `tiktok` | реклама зазвичай 9–30 с; гачок у перші 1–2 с |
| Instagram Reels | 9:16, 1080×1920 | `reels` | обкладинка в сітці профілю обрізається до 3:4 (1080×1440) |
| YouTube Shorts | 9:16, 1080×1920 | `shorts` | — |
| Instagram/Facebook стрічка | 4:5, 1080×1350 | `feed45` | також 1:1 (`square`) |
| YouTube | 16:9, 1920×1080 / 3840×2160 | `youtube` / `youtube4k` | мініатюра 1280×720 |
| Майстер-копія для Resolve | вихідний розмір | `master` | ProRes 422 HQ + PCM |

Технічні параметри пресетів mtk: H.264 High, yuv420p, AAC 48 кГц стерео, `+faststart`,
гучність −14 LUFS інтегрально, true peak −1.5 dBTP (двопрохідний loudnorm). Кадрова частота — як у джерела (до 60).

Безпечні зони вертикального відео (приблизно, для 1080×1920): не розміщуй важливий текст у верхніх ~220 px,
нижніх ~420 px і правих ~140 px — там кнопки й підписи інтерфейсу. Субтитри mtk `tiktok` розміщені вище нижньої зони.

Перевірка перед публікацією: `mtk probe _out` (розмір/тривалість/звук), `mtk loudness файл`, `mtk frames файл --at 0:01,0:05`.
