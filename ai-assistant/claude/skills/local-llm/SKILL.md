# Локальна модель (llm-local)

## Коли варто
- Обсяг великий, задача проста, помилка дешева і перевірювана: опис 200 кадрів/аркушів, розкласти 500 файлів за 5 категоріями,
  чорновий підсумок 50 транскриптів, щоб вибрати, які читати уважно.
- Економія: модель Claude читає лише короткі результати (рядок на файл) замість самих файлів.

## Коли НЕ варто
- Остаточні рішення, код, юридичні/фінансові тексти, тексти для клієнтів без перевірки, усе, де потрібна точність понад «приблизно».
- Мало даних (до ~10 файлів) — швидше й якісніше зробити самому.

## Команди
- `llm-local status` — чи працює Ollama, які моделі, чи вимкнена хмара.
- `llm-local caption <папка|файли> --save _out/captions.txt` — опис зображень (кадри з `mtk frames`, аркуші з `mtk sheet`).
- `llm-local classify <папка> --labels "товар,люди,пейзаж,брак"` — категорія на файл.
- `llm-local summarize <файли.txt> --words 120` — стисло, по шматках.
- `llm-local ask "питання" --file дані.txt` — довільна проста задача; `--json` для структурованої відповіді.

## Обов'язково
- Перевір випадкову вибірку (≈10%, мінімум 3) сам; якщо якість погана — не використовуй результат, скажи власнику.
- Код виходу 3 (LOCAL_LLM_UNAVAILABLE) = немає Ollama/моделі: продовжуй без неї (сам або на вибірці), не зупиняй задачу.
- Лише локально: хмарні моделі Ollama заборонені інструментом; не змінюй OLLAMA_HOST на зовнішній.
