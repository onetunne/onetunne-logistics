# Автоматизація

## Порядок вибору способу (від найдешевшого й найнадійнішого)
1. Скрипт (PowerShell/Python) — файли, папки, таблиці, звіти, API.
2. CLI-програми (`gh`, `ffmpeg`, `mtk`, `playwright-cli`).
3. MCP/конектори програм (DaVinci Resolve, Blender, Affinity…).
4. Браузер: Claude in Chrome (сайти, де власник уже увійшов) або `playwright-cli` (повторювані сценарії, тести).
5. Computer Use у Claude Desktop — лише якщо інакше ніяк (найдорожче й найповільніше).

## Правила безпечних скриптів
- Спершу «сухий прогін»: скрипт показує, що зробить (`-WhatIf` / `--dry-run`), і лише після підтвердження виконує.
- Нічого не видаляти: переміщувати в `_trash\<дата>\` з журналом «звідки → куди», щоб можна було повернути.
- Ідемпотентність: повторний запуск не ламає результат (пропускає вже оброблене).
- Журнал у файл (`logs\<задача>-<дата>.log`), у відповідь — лише підсумок.
- Шляхи з пробілами й кирилицею — завжди в лапках; кодування UTF-8.

## Розклад (Windows Task Scheduler)
Створення задачі змінює систему — лише з підтвердженням власника. Шаблон:
`schtasks /Create /TN "Assistant\<назва>" /SC DAILY /ST 09:00 /TR "powershell -NoProfile -File C:\path\task.ps1"`.
Перевірка: `schtasks /Query /TN "Assistant\<назва>"`. Видалення — теж із підтвердженням.

## Браузер
- `playwright-cli` + його skill (встановлено інсталятором): відкрити сторінку, клікнути, заповнити, зробити знімок — компактно.
- Логіни, паролі, оплати, надсилання форм/повідомлень — лише з підтвердження власника; паролі не вводь і не зберігай у скриптах.

## Приклади задач
- Розкласти завантаження за типами/датами → скрипт з `--dry-run`, потім виконання.
- Перейменувати сотні фото за датою зйомки → ExifTool/PowerShell, журнал перейменувань.
- Щоденний звіт з CSV/Excel → Python + skill xlsx, результат у папку `Звіти`.
