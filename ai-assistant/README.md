# Універсальний помічник Claude — пакет налаштувань

Глобальна конфігурація Claude для роботи на комп'ютері: монтаж відео (DaVinci Resolve, FFmpeg, Whisper),
анімація, дизайн, розробка, автоматизація, бізнес-задачі. Ставиться однаково на будь-який ПК з Windows,
сам підлаштовується під залізо і працює навіть без локальних моделей.

Аналіз інструментів, схема й пояснення економії лімітів — у [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Що входить

| Папка/файл | Що це |
|---|---|
| `install.cmd` | встановлення (подвійний клік); питає перед кожним кроком |
| `backup.cmd` / `restore.cmd` | бекап конфігурації **без паролів і ключів** / відновлення на іншому ПК |
| `update.cmd` | оновити пакет і повторно застосувати налаштування |
| `claude/` | правила, 5 агентів, 6 skills, шаблон налаштувань (розгортається в `%USERPROFILE%\.claude`) |
| `tools/` | утиліти: `mtk` (відео), `llm-local` (локальна модель), захист, рядок стану, `assistant-setup` |
| `config/` | каталоги компонентів і локальних моделей (легко оновлювати) |

## Встановлення — покроково

**Потрібно:** Windows 10 (1809+) або 11, інтернет, ~15 ГБ вільного місця (+ 4–20 ГБ, якщо ставити локальні моделі),
підписка Claude (Pro або Max).

1. **Отримайте папку `ai-assistant`**: ZIP із чату (або GitHub → гілка `claude/universal-ai-assistant-setup-lv7rvv`
   → Code → Download ZIP). Перед розпакуванням: правий клік на ZIP → Властивості → поставте «Розблокувати» → OK.
   Розпакуйте, наприклад, у `C:\AI\ai-assistant`.
2. **Запустіть `install.cmd`** подвійним кліком. Якщо Windows покаже «Захист ПК» — «Докладніше» → «Виконати однаково».
   Інсталятор покаже план і питатиме «так/ні» перед кожним етапом. На запити Windows «Дозволити зміни?» відповідайте «Так»
   (це встановлення Git/Node/FFmpeg). Спершу можна подивитись план без змін:
   `powershell -NoProfile -ExecutionPolicy Bypass -File install.ps1 -DryRun`.
3. **Відкрийте нове вікно термінала** (Пуск → «Terminal») і введіть `claude` → увійдіть у свій акаунт у браузері.
   Або відкрийте Claude Desktop → вкладка **Code** (налаштування ті самі).
4. **Мова і голос**: у Claude Code введіть `/config` → мова → Ukrainian. Далі `/voice` — тримайте Пробіл і говоріть.
5. **Ручні кроки (5 хв)**:
   - DaVinci Resolve Studio: оновіть до **21.1 або новішої** → File → **Setup AI Assistants** → Claude Code (і Claude Desktop).
     Там же: Preferences → System → General → External scripting using: **Local**.
   - Chrome: встановіть розширення **Claude** з Chrome Web Store, увійдіть; у Claude Code — `/chrome`.
   - Для розробки (за бажанням): `npx ctx7 setup --claude` → режим «CLI + Skills» → безкоштовний вхід.
6. **Перевірка**: напишіть Claude «Перевір, що все встановлено» (або `assistant-setup doctor`).
7. **Бекап**: `backup.cmd` → ZIP у «Документи\Claude-backups» (без секретів).

**Хочете, щоб усе зробив Claude?** У Claude Desktop: Settings → Claude Code → Remote Control → додайте папку
`C:\AI\ai-assistant`. Тоді хмарна сесія Claude зможе запустити встановлення на вашому ПК (ви підтверджуєте доступ і запити Windows).

## Як користуватися (приклади фраз)

- «Ось папка D:\Відео\Зйомка. Знайди 5 найкращих моментів і зроби 3 ролики по 15 с для TikTok із субтитрами й логотипом.»
- «Зроби вертикальні версії всіх відео з D:\Відео\Огляди для Reels, субтитри українською, вирівняй гучність.»
- «У відкритому проєкті Resolve розклади кліпи по бінах і постав у рендер усі таймлайни в 1080p.»
- «Виріж паузи з інтерв'ю і віддай таймлайн у Resolve.»
- «Зроби 10 банерів для Instagram з цінами з prices.xlsx у нашому стилі.»
- «Розклади файли в Завантаженнях за типами» (спершу покаже, що зробить).
- «Знайди безкоштовну альтернативу … і порівняй» → агент-дослідник.
- «Перевір безпеку проєкту» → агент безпеки. «Перевір готовий ролик перед публікацією» → агент контролю якості.

Агенти запускаються лише коли це вигідно — вони витрачають ліміти підписки.
Рядок стану внизу Claude Code показує модель, заповнення контексту і використання лімітів (5 год / 7 днів).

## Голос, екран, керування комп'ютером

| Задача | Як |
|---|---|
| Говорити українською | `/voice` у Claude Code (розпізнавання не витрачає токенів); у будь-якій програмі — Handy (офлайн, необов'язково) |
| Показати екран | Win+Shift+S → вставити скріншот у Claude Desktop (або перетягнути файл у термінал) |
| Керувати браузером | Claude in Chrome (ваші сайти з входом), `playwright-cli` (автоматизація) |
| Керувати програмами | спершу MCP/скрипти (Resolve, Blender…); інакше Computer Use у Claude Desktop (Windows, Pro/Max) — найдорожчий спосіб |
| Працювати з телефона | Claude-застосунок → Remote Control до сесії на ПК |

## Перенесення на інший комп'ютер
1. На старому ПК: `backup.cmd` → ZIP (без паролів/ключів).
2. На новому: скопіюйте папку `ai-assistant` (або завантажте ZIP) → `install.cmd` (сам визначить залізо і моделі).
3. Перетягніть ZIP бекапу на `restore.cmd`. Ключі API, якщо були, введіть заново — вони навмисно не зберігаються.

## Безпека
- Захисний хук блокує катастрофічні дії (форматування, видалення домашньої/системних папок, доступ до облікових даних)
  і питає вас про ризиковані (видалення файлів, встановлення програм, системні зміни, `git push`, надсилання повідомлень,
  платежі, накладні, зміни магазину, читання `.env`). Працює навіть в автоматичних режимах.
- Нічого не видаляється без вашого «так»; оригінали відео не змінюються (результати — в `_out`).
- Прибрати все наше: `assistant-setup undeploy` (переміщує в резервну копію, нічого не стирає).
- Екстрено вимкнути захист: змінна середовища `ASSISTANT_GUARD=off` (лише ви, вручну).

## Стан (чесно)
- **Перевірено** (у Linux-контейнері): 18 автотестів утиліт, реальна обробка відео FFmpeg (аналіз, нарізка з переходами,
  вертикальний рендер із субтитрами, OTIO-таймлайн, пакетна обробка з продовженням), встановлення через `uv`,
  розгортання/бекап/відновлення, захисний хук, рядок стану; `install.ps1` — синтаксис і сухий прогін у PowerShell 7.4.
- **Не перевірено ще**: запуск на реальному Windows (winget, PowerShell 5.1), DaVinci Resolve (API і вбудований MCP),
  справжня транскрипція Whisper і моделі Ollama, апаратне кодування на відеокарті, хук усередині живої сесії Claude Code.
  Усе це перевіримо на вашому ПК командою `assistant-setup doctor` і пробним роликом.
- Назви локальних моделей і ліміти платформ — станом на 26.11.2026; оновлюються в `config/` без зміни коду.
