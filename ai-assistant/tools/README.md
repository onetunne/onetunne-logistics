# assistant-tools

Локальні утиліти універсального помічника (Python ≥ 3.10, ядро — лише стандартна бібліотека).

| Команда | Призначення |
|---|---|
| `mtk` | медіа-набір: аналіз, транскрипція, пошук моментів, нарізка, вертикальні версії, субтитри, експорт, пакетна обробка, DaVinci Resolve |
| `llm-local` | делегування простих задач локальній моделі Ollama (з відмовою, якщо її немає) |
| `assistant-guard` | PreToolUse-хук Claude Code: блокує небезпечні дії, просить підтвердження для ризикових |
| `assistant-statusline` | рядок стану: модель, заповнення контексту, ліміти 5 год / 7 днів |
| `assistant-setup` | визначення заліза, план моделей, розгортання конфігурації, бекап без секретів, відновлення, діагностика |

Встановлення (робить інсталятор): `uv tool install --editable ./tools --with faster-whisper`.
Тести: `python -m unittest discover -s tests -v` (з каталогу `tools`).
