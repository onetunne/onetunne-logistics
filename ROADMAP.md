- Стани накладної: compare-and-set для всіх переходів, звірка лише для creating/unknown, пізня відповідь перевізника →
  ручний розгляд, заборона редагування даних під час створення накладної, відмова перевізника скасувати не ігнорується,
  ручне прив'язування атомарне й скасовується лише локально.
- Безпека: сервер із довірою до HTTPS-проксі (без цього форми на Render/Shopify відхилялися б), перевірка Origin для
  ресурсних маршрутів, ліміти входу в демо за IP сервера + загальний ліміт, cookie демо прив'язане до пароля,
  у журналах немає тексту SQL/параметрів, повторна обробка webhook після збою.

- Перевірка даних (після огляду): місцевий номер, дійсний і в країні доставки, і в Україні (країна відправлення),

- Демо на «чистому» завантаженні: автоматичне створення папки даних, шаблон бази під час збірки (менше пам'яті),

### Доопрацювання після ручного тестування (перевірено автотестами; повторна перевірка в магазині — за власником)
- Міжнародна адреса: у `orderUpdate` усі поля адреси передаються явно, регіон — лише кодом (раніше при зміні країни
  в Shopify могли лишатися старі регіон/індекс). Помилки Shopify прив'язуються до полів форми з текстом Shopify;
  адреса з помилками перевірки в Shopify не надсилається.
- Після успішного оновлення попередні помилки синхронізації й «мертві» завдання закриваються автоматично.
- Залишки: невідстежуваний у Shopify залишок = «не відстежується» (раніше міг показуватися як 0); таблиця залишків
  для звірки на сторінці синхронізації; товари з багатьма варіантами перечитуються повністю.
- Імпорт: помилка одного замовлення не зупиняє імпорт (повторюється окремо), лічильники нових/оновлених/невдалих,
  попередження про обмеження 60 днів і інструкція для `read_all_orders`; розміри сторінок у межах ліміту вартості GraphQL.
- Документація Render: команда збірки `npm ci --include=dev && npm run build`.
- Зміна країни доставки (повторне тестування: DE → «Country/region not supported»): параметри `orderUpdate` звірено зі
  схемою 2026-10 (`countryCode` — enum CountryCode, без застарілих `country`/`province`, `shippingAddress` перезаписує адресу
  повністю). Додано перевірку країн доставки магазину (`shop.shipsToCountries`, `countriesInShippingZones`) перед запитом
  із точним поясненням біля поля «Країна», показ країн доставки на сторінці синхронізації і звірку застосованої країни
  у відповіді Shopify. Регресійні тести UA → DE.
- Повторне тестування: DE є в зонах доставки, помилка лишилася → причину ще не встановлено. Додано безпечне журналювання
  кожного `orderUpdate` (форма запиту, стан адреси й способу доставки в Shopify до запиту, userErrors, X-Request-Id;
  без ПД/токенів) і покрокову діагностику для власника. Очікується результат діагностики з реального магазину.
