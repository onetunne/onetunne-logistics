### Результати перевірки (фактично виконано)
- `npm run typecheck` — без помилок (TypeScript strict).
- `npm test` — 26 файлів, 287 тестів пройдено (PGlite).
- Інтеграційні тести на справжньому PostgreSQL 16 (`TEST_DATABASE_URL=… npx vitest run tests/integration`) — 28/28.
- `npm run build` — успішно.
- E2E у Chromium (`npm run test:e2e`, iPhone 13 + ПК 1440px, «чиста» база) — 18/18 перевірок: сценарій
  «оплачене → перевірка → проблема → ручне виправлення → тестова накладна», повторний запит створення не дає дубліката
  (накладна у списку рівно один раз), масова перевірка, розділ «Проблеми», без горизонтальної прокрутки на iPhone,
  403 для працівника в налаштуваннях, без помилок у консолі браузера.
- Пам'ять демо-сервера: ~400 МБ (виміряно локально, з шаблоном бази зі збірки; без нього ~730 МБ).

### Незалежний огляд коду (виконано, знахідки виправлено)
- Стани накладної: compare-and-set для всіх переходів, звірка лише для creating/unknown, пізня відповідь перевізника →
  ручний розгляд, заборона редагування даних під час створення накладної, відмова перевізника скасувати не ігнорується,
  ручне прив'язування атомарне й скасовується лише локально.
- Безпека: сервер із довірою до HTTPS-проксі (без цього форми на Render/Shopify відхилялися б), перевірка Origin для
  ресурсних маршрутів, ліміти входу в демо за IP сервера + загальний ліміт, cookie демо прив'язане до пароля,
  у журналах немає тексту SQL/параметрів, повторна обробка webhook після збою.

- Перевірка даних (після огляду): місцевий номер, дійсний і в країні доставки, і в Україні (країна відправлення),
  тепер неоднозначний → вибір менеджера; відмова перевізника блокує замовлення до виправлення або свідомого закриття;
  відхилені попередження не повертаються; скасування замовлення закриває його проблеми; LU-індекси «L-1234».
- Демо на «чистому» завантаженні: автоматичне створення папки даних, шаблон бази під час збірки (менше пам'яті),
  `.env` підхоплюється `npm run demo`/`npm start`, довіра до проксі лише за `TRUST_PROXY` (увімкнено в render.yaml).

### Поточні обмеження етапу 1
- Немає підключення до Shopify (етап 2): дані лише демонстраційні; у робочому режимі (`/app`) списки порожні.
- Nova Global не інтегровано (немає документації та ключів) — у робочому режимі накладні створити неможливо.
- Пошук відсутнього індексу за довідниками не реалізовано (лише проблема з поясненням).
- Правила країн — значення за замовчуванням, потребують перевірки; редагування — етап 4.
- Фонова черга завдань і автоматичні повторні спроби — лише схема (етап 2).
- Друк PDF (накладні, інвойси, комплектувальні листи) — етап 3.
- ESLint не налаштовано (перевірка типів TypeScript strict + тести).
- Вбудований режим у Shopify Admin не перевірявся (етап 2, потрібні ключі). Мова/тема у вбудованому режимі зберігаються в Partitioned-cookie — перевірити на етапі 2.

## Етап 2 — інтеграція Shopify (план, не розпочато)
1. Підготовка (власник): застосунок у Shopify Dev Dashboard (Custom Distribution на onetunne.com), хостинг робочої версії
   та PostgreSQL, ключі в змінних середовища (не в коді).
2. Підключення: `shopify app config link`, мінімальні scopes, Protected Customer Data, встановлення в магазин,
   перевірка вбудованого режиму (App Bridge, навігація, мова/тема в iframe).
3. Ролі: власник за `OWNER_SHOPIFY_USER_IDS`, інші — «Працівник»; розділ «Працівники» (базовий).
4. Робочий ShopifyGateway (GraphQL Admin API 2026-10): читання замовлень/товарів/варіантів/фото/ваги/митних даних/залишків.
5. Webhooks (orders/create, orders/paid, orders/updated, orders/cancelled, products/update, inventory) з перевіркою HMAC
   і захистом від повторів; фонова черга на таблиці `jobs` з повторними спробами та відновленням після перезапуску.
6. Імпорт старих замовлень (read_all_orders — після схвалення Shopify) з ручним запуском і прогресом.
7. Оновлення адреси/контактів у Shopify після підтвердженого виправлення; синхронізація статусів і скасувань.
8. Тести: юніт/інтеграційні з записаними відповідями API, перевірка на development store, потім — на робочому магазині
   лише з дозволу власника. Чинний застосунок доставки не відключається.
